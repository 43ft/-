# 增量挖矿小游戏 - 项目开发计划

## 一、项目概述

本项目是一款基于微信小程序的增量类挖矿游戏，核心玩法为"挖矿获取资源 → 升级天赋/装备 → 更高效挖矿"的循环机制。游戏融合了放置类、养成类和策略类元素，为玩家提供丰富有趣的游戏体验。

## 二、核心玩法设计

### 2.1 游戏循环
```
挖矿获取资源 → 升级天赋/装备 → 解锁新矿层 → 更高效挖矿
```

### 2.2 核心系统

| 系统名称 | 功能描述 | 重要性 |
| :--- | :--- | :--- |
| 挖矿系统 | 核心玩法，点击或自动挖矿获取矿石 | 高 |
| 天赋系统 | 升级技能提升挖矿效率 | 高 |
| 背包系统 | 管理矿石、道具 | 中 |
| 矿层系统 | 解锁新矿层获取稀有矿石 | 高 |
| 成就系统 | 完成任务获得奖励 | 中 |
| 商店系统 | 购买道具和加速卡 | 中 |

## 三、功能模块详细设计

### 3.1 挖矿系统

**矿石类型：**
| 矿石 | 基础价值 | 稀有度 | 解锁矿层 |
| :--- | :--- | :--- | :--- |
| 煤矿 | 1金币 | 普通 | 第1层 |
| 铁矿 | 5金币 | 普通 | 第1层 |
| 铜矿 | 15金币 | 稀有 | 第2层 |
| 银矿 | 50金币 | 稀有 | 第3层 |
| 金矿 | 150金币 | 史诗 | 第4层 |
| 钻石矿 | 500金币 | 传说 | 第5层 |
| 红宝石 | 1500金币 | 神话 | 第6层 |

**挖矿方式：**
- 手动点击挖矿
- 自动挖矿（需解锁）
- 连点加成（连续点击获得额外奖励）

### 3.2 天赋系统

**天赋树分类：**

| 天赋类别 | 效果描述 |
| :--- | :--- |
| 力量系 | 提升单次挖矿产出 |
| 效率系 | 提升挖矿速度 |
| 幸运系 | 提升稀有矿石掉率 |
| 财富系 | 提升金币加成 |
| 自动系 | 解锁自动挖矿功能 |

**天赋升级机制：**
- 消耗金币升级
- 等级越高消耗越大
- 效果叠加

### 3.3 矿层系统

| 矿层 | 解锁条件 | 矿石种类 | 特色 |
| :--- | :--- | :--- | :--- |
| 煤洞 | 初始解锁 | 煤矿、铁矿 | 基础矿层 |
| 铜矿坑 | 1000金币 | 铜矿、银矿 | 中等难度 |
| 水晶矿 | 10000金币 | 金矿 | 高价值 |
| 深渊矿 | 50000金币 | 钻石矿 | 稀有 |
| 秘境 | 200000金币 | 红宝石 | 传说 |

### 3.4 成就系统

| 成就名称 | 达成条件 | 奖励 |
| :--- | :--- | :--- |
| 初出茅庐 | 累计挖矿100次 | 100金币 |
| 挖矿达人 | 累计挖矿1000次 | 1000金币 |
| 百万富翁 | 累计获得100万金币 | 特殊称号 |
| 矿洞探险家 | 解锁所有矿层 | 钻石奖励 |
| 天赋大师 | 任意天赋满级 | 专属头像框 |

### 3.5 商店系统

| 道具名称 | 价格 | 效果 |
| :--- | :--- | :--- |
| 矿工镐 | 500金币 | 提升挖矿效率50%持续5分钟 |
| 幸运符 | 1000金币 | 稀有矿石掉率翻倍持续3分钟 |
| 自动挖矿卡 | 2000金币 | 开启自动挖矿10分钟 |
| 金币加倍卡 | 3000金币 | 金币获取双倍持续5分钟 |
