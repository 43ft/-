# 挖矿大亨 - 游戏设计规格说明书

## 一、游戏概述

### 1.1 游戏定位
《挖矿大亨》是一款基于微信小程序的增量类挖矿游戏，核心玩法为"挖掘 N×N×N 矿区获取矿石 → 升级装备 → 更高效挖掘更大矿区"的循环机制。

### 1.2 核心循环
```
挖掘矿区获取矿石 → 升级装备提升效率 → 挑战更大矿区 → 获取稀有矿石 → 制作高级装备
```

### 1.3 游戏特色
- **三维矿区**：每个矿层为 N×N×N 的立方体，N 逐层递增
- **纪元推进**：每5层为一个纪元，拥有独特主题和环境
- **工业风格**：装备涵盖矿镐、炸药、电钻、自动采掘机等硬核工业设备
- **渐进解锁**：矿区规模、矿石类型、装备等级随进度逐步解锁

## 七、核心算法

### 7.1 矿石生成算法

```
FUNCTION generateOreBlock(depth, era)
  // depth: 0-1, 0=顶层, 1=底层
  // era: 1-6+

  baseChance = getEraOreChance(era)
  depthBonus = depth * 0.3    // 底层稀有概率+30%

  FOR each oreType IN eraOres[era]
    IF random() < oreType.chance + depthBonus * oreType.rareBonus
      RETURN oreType.id
    END
  END

  RETURN oreType.basic.id     // 默认基础矿石
END
```

### 7.2 挖掘速度计算

```
FUNCTION calculateMineSpeed(equipment, oreType, era)
  baseSpeed = 1.0             // 基础速度

  // 装备加成
  pickaxeBonus = getPickaxeBonus(equipment.pickaxe)
  drillBonus = getDrillBonus(equipment.drill, oreType)

  // 环境惩罚
  environmentPenalty = getEnvironmentPenalty(era)

  // 最终速度
  finalSpeed = baseSpeed * (1 + pickaxeBonus) * (1 + drillBonus) * (1 - environmentPenalty)

  RETURN finalSpeed
END
```

### 7.3 矿区规模计算

```
FUNCTION calculateLayerSize(layer)
  // layer从1开始
  n = layer + 1               // 第1层=2×2×2, 第2层=3×3×3, ...
  size = n * n * n
  RETURN {
    dimension: n,
    totalBlocks: size
  }
END
```
